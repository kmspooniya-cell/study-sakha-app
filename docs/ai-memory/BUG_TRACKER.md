## BUG-017 — Group chat temporarily cleared after send
- **Severity:** High
- **Root cause:** `GroupsScreen` replaced the channel array with the result of an initial `getStudyGroupMessages` request. If a send or realtime INSERT completed before that request, the stale response removed the newer message from local state.
- **Fix:** Merge fetch, optimistic server response, and realtime INSERTs by message id; sort by server `created_at`; ignore stale request completions; restore the draft on failed sends; do not fabricate messages without Supabase.
- **Verification:** Focused group chat/realtime tests pass; live multi-client Supabase and Android persistence remain not verified in this environment.
